# dokusy 言語仕様 M0

最終更新日: 2026-02-18

## 1. 目的
- イントラ環境でも安全・快適に動作する小さな言語を提供する。
- Rust風の記法（`let`, `fn`, `match` など）を一部採用するが、Rust互換は目指さない。

## 2. M0のスコープ
- 実行形態: インタプリタ
- モジュール/名前空間: 未対応（importなし）
- `&` / `*`（参照外し）/ ライフタイム / `::`: 言語機能として不採用

## 3. 字句仕様
- コメント: `//` から行末まで
- 文字列: `"..."`（対応エスケープ: `\"`, `\\`, `\n`）
- 数値: 10進 `i64`（符号は単項演算子で扱う）

## 4. 型（M0）
- `i64`
- `bool`
- `string`
- `()`（unit）
- `null` は存在しない

## 5. 文法要素（M0）
### 5.1 文
- 変数宣言: `let x = expr;` / `let mut x = expr;`
- 代入: `x = expr;`（`mut` でない変数への代入は実行時エラー）
- ブロック: `{ stmt* }`
- if: `if cond { ... } else { ... }`
- while: `while cond { ... }`
- return: `return expr;`

### 5.2 関数
- 定義: `fn name(a: i64, b: i64) -> i64 { ... }`
- 呼び出し: `name(expr, expr)`
- 組み込み: `print(expr);`（改行付き）
- エントリポイント: `dokusy run` は `main()` を自動で呼び出す

### 5.3 演算子優先順位（高→低）
1. 単項: `!`, `-`
2. 乗除: `*`, `/`
3. 加減: `+`, `-`
4. 比較: `==`, `!=`, `<`, `<=`, `>`, `>=`
5. 論理: `&&`, `||`

## 6. 実装上の制約（現状）
- パーサ: 手書き再帰下降パーサ
- 実行時: 動的値で評価しつつ、関数戻り値型を検証
- エラー: lexer / parser / runtime で行・列を保持

## 7. 未実装・任意機能
- `match` はM0では未実装（将来拡張予定）
- `repl` はプレースホルダ実装（未実装表示のみ）
